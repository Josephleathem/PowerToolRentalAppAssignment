# Week 3: Hands On - Power Tool Rental App


## Learning Objectives

CO4 Create and customize an Android project with icons and interactive components, such as RadioButtons, applying layout and alignment attributes, implementing conditional statements for decision-making, and displaying notifications.

## Assignment Prompt

Design a Power Tool Rental App. The app determines the cost of a power washer or tiller. The opening screen requests the number of days that the power tool will be rented.

The user selects a radio button labeled Power Washer or Tiller and then selects the Compute Cost button.

The final cost is displayed for the number of days rented.

The result is rounded off to the nearest penny.

The power washer costs $55.99 a day and the tiller costs $68.99 a day.

Do not enter more than seven days.

Locate an image online and resize it for use as a custom launcher icon and Action bar icon.

## Assignment Submission

For each program, attach the two required files to your submission:

1. Copy/paste your code and output screenshots into a Microsoft Word file.
2. Your source files.

# Week 3: Assignment - Power Tool Rental App Part II

## Learning Objectives Covered

CO4 Create and customize an Android project with icons and interactive components, such as RadioButtons, applying layout and alignment attributes, implementing conditional statements for decision-making, and displaying notifications.

## Assignment Prompt

In this project, you'll be working on Part II of the Power Tool Rental App. For Part 2, add these features to enhance the app's functionality and engagement for users:

### Rental Summary Screen

After computing the cost, display a summary screen showing a breakdown of the rental, including the tool type, daily rate, number of days, and total cost.

### Tool Information Section

- Include a brief description or list of features for each tool (power washer and tiller) to help users make an informed choice.
- Display images of each tool to add visual appeal and clarity.

### Error Handling for Invalid Entries

- Display a prompt if a user enters more than seven days, reminding them of the rental limit.
- Handle non-numeric or empty inputs for the rental days field with a helpful message.

### Help and FAQ Section

Provide a short FAQ or help button explaining pricing, rental limits, and any additional policies or guidelines for tool rental.
